# دليل التطوير

## بدء العمل

```bash
npm run dev
```

افتح `http://127.0.0.1:4173` واسمح للمتصفح باستخدام الميكروفون.

## الفحص قبل الحفظ أو النشر

```bash
npm run check
```

المشروع بلا اعتماديات npm تشغيلية في الوقت الحالي.

## قواعد تعديل الصوت

- عدم تشغيل صوت مترونوم داخل مسار التسجيل.
- عدم إضافة صدى أو تطبيع أو تغيير طبقة إلى WAV المرجعي.
- عدم العودة إلى `ScriptProcessorNode`.
- المحافظة على مصفوفة PCM متصلة بلا فقد كتل.
- عدم اعتماد التسجيل إذا كشف فحص الجودة قفزة رقمية داخلية.
- توضيح الفرق بين 12-TET و24-TET للمستخدم.

## اختبار يدوي أساسي

اختبر تشغيل الميكروفون، ظهور التردد، القيم الزمنية الأربع، الاستماع، تصدير WAV وMP3 وZIP وCSV، بقاء التسجيلات بعد إعادة التحميل، والإلغاء ومسح المكتبة.

## إدارة الإصدار

حدّث `VERSION.json` و`package.json` و`index.html` و`CHANGELOG.md`، ثم شغّل `npm run check` واستخدم رسالة commit وصفية.

بحسب قرار صاحب المشروع، يجري التطوير حاليًا مباشرة على `main`، ولذلك يجب الالتزام بالفحص الآلي قبل كل تحديث.
