# مِعيار الناي — Ney Meyar

- الإصدار: **v0.4.0**
- تاريخ الإصدار: **2026-08-02**
- صاحب حقوق الملكية الفكرية: **محمد الزهراني**
- الحالة: Beta

## أبرز الوظائف
- أسماء عربية وإنجليزية.
- نصف تون وربع تون.
- A4 = 440 Hz.
- YIN لتقدير التردد الأساسي.
- فحص SNR والوضوح والثبات والاستمرار.
- تسجيل كل نغمة أربع عدّات محسوبة من BPM.
- عداد مرئي صامت.
- زر سماع لكل تسجيل.
- WAV وMP3.
- تحديد التسجيلات وتصدير المحدد أو الكل داخل ZIP.
- تخزين التسجيلات في IndexedDB.
- رقم الإصدار والتاريخ وحقوق الملكية داخل التطبيق والملفات.

## التشغيل
ارفع الحزمة كاملة مع مجلد `vendor` إلى GitHub Pages أو Cloudflare Pages أو Vercel.

للتشغيل محليًا:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## ملاحظة MP3
WAV يعمل محليًا دون اتصال. محول MP3 يحتاج اتصالًا بالإنترنت عند أول استخدام لتحميل مكتبة LAME.
