## التعديلات الرئيسية في v0.5.0

- استبدال ScriptProcessorNode القديم بـ AudioWorklet.
- تسجيل العينات داخل مسار الصوت الحقيقي بدل الخيط الرئيسي للواجهة.
- تجميع كل نغمة في مصفوفة متصلة واحدة لمنع فواصل الكتل.
- فحص آلي للقفزات الرقمية والطقطقة قبل قبول الملف.
- إضافة القيم الزمنية:
  - روند: 4 عدّات.
  - بلانش: عدّتان.
  - نوار: عدّة واحدة.
  - كروش: نصف عدّة.
- حساب المدة تلقائيًا من BPM.
- إضافة زر **مسح القائمة بالكامل** مع تأكيد.
- إضافة نوع العلامة وعدد العدّات إلى اسم الملف وبيانات التصدير.
- استمرار دعم سماع التسجيلات والتصدير الفردي والجماعي.

## التشغيل

يجب رفع الحزمة كاملة، بما فيها:

- `index.html`
- `audio-recorder-worklet.js`
- مجلد `vendor`

إلى خدمة HTTPS مثل GitHub Pages أو Cloudflare Pages أو Vercel.

للتشغيل محليًا:

```bash
python -m http.server 8000
```

ثم افتح:

```text
http://localhost:8000
```

فتح `index.html` مباشرة بصيغة `file://` لا يضمن تشغيل AudioWorklet.

## القيم الزمنية

المدة تحسب بهذه العلاقة:

```text
المدة بالثواني = عدد العدّات × 60 ÷ BPM
```

مثال عند 60 BPM:

- روند = 4 ثوانٍ.
- بلانش = ثانيتان.
- نوار = ثانية واحدة.
- كروش = نصف ثانية.

## جودة الصوت

- WAV هو الملف المرجعي الخام.
- لا يستخدم التطبيق صدى أو تغيير طبقة أو تطبيعًا أو مؤثرات.
- العداد مرئي وصامت.
- التطبيق يرفض التسجيل عند اكتشاف طقطقة رقمية داخلية.
