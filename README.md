# مِعيار الناي — Ney Meyar

أداة ويب عربية لتسجيل نغمات الناي وتحليلها وفق مرجع `A4 = 440 Hz`، مع دعم شبكتي `12-TET` و`24-TET`، وحفظ التسجيلات وتصديرها بصيغ مناسبة للأرشفة.

## حالة المشروع

- الإصدار الحالي: **v0.5.1**
- الحالة: **Beta**
- تاريخ الإصدار البرمجي: **2026-08-02**
- تاريخ تجهيز المستودع للتطوير المنظم: **2026-08-05**
- المالك وصاحب حقوق المشروع: **محمد الزهراني**
- الفرع المعتمد للتطوير حاليًا: `main`

يُعد ملف [`VERSION.json`](VERSION.json) المصدر المعتمد لبيانات الإصدار.

## المزايا الحالية

- التقاط PCM باستخدام `AudioWorklet` بدل `ScriptProcessorNode`.
- تسجيل روند وبلانش ونوار وكروش بحسب عدد العدّات وBPM.
- دعم القياس وفق `12-TET` و`24-TET`.
- فحص القفزات الرقمية والطقطقة قبل قبول التسجيل.
- حفظ التسجيلات محليًا داخل المتصفح.
- الاستماع والتصدير الفردي والجماعي.
- تصدير WAV وMP3 وCSV وحزمة ZIP.
- عداد مرئي صامت لا يتداخل مع التسجيل.

## متطلبات التطوير

- Node.js 20 أو أحدث.
- متصفح حديث يدعم Web Audio API وAudioWorklet.
- تشغيل المشروع عبر `localhost` أو HTTPS؛ فتح `index.html` بصيغة `file://` غير مدعوم.

## التشغيل محليًا

```bash
npm run dev
```

ثم افتح:

```text
http://127.0.0.1:4173
```

## فحص المشروع

```bash
npm run check
```

يتحقق الفحص من وجود الملفات الأساسية، وتطابق الإصدار والمالك، وصحة بناء JavaScript الأساسي، وبقاء AudioWorklet ضمن الحزمة.
